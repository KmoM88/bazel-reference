# 2. Deep Dive: C++ (The Bedrock)
Goal: Master native C++ rules, manage external dependencies using the stable `WORKSPACE` mechanism, and conquer C++ gRPC integration.

Strategy: To ensure maximum compatibility with C++ toolchains, we will define all external dependencies (GoogleTest, gRPC, Protobuf) in the `WORKSPACE` file. The `MODULE.bazel` file will remain empty except for the project definition.

## 2.0 Environment Configuration
Before writing code, let's set up the "Clean Slate" configuration.

### 1. `MODULE.bazel` (Minimal)
We define the project but do not add any dependencies here.

```
module(
    name = "my_bazel_project",
    version = "0.1.0",
)
```
### 2. `WORKSPACE` (The Dependency Manager)
Start with an empty file. We will add to it in sections 2.2 and 2.3.

```
# WORKSPACE
# Currently empty. We will add dependencies here later.
```
### 3. `.bazelrc`
```bash
# .bazelrc
build --repo_env=CC=gcc
build --cxxopt='-std=c++17'
```
## 2.1 Basic C++: Libraries & Binaries
We will create a simple library that generates a greeting and a main binary that prints it.

### 1. Directory Structure
```
workspace_root/
└── src/
    ├── lib/
    │   ├── BUILD.bazel
    │   ├── greeter.h
    │   └── greeter.cc
    └── main/
        ├── BUILD.bazel
        └── main.cc
```
### 2. The Library (`src/lib`)
`src/lib/greeter.h`
```c++
#ifndef LIB_GREETER_H_
#define LIB_GREETER_H_
#include <string>

namespace simple_app {
    std::string GetGreet(const std::string& who);
}

#endif
```
`src/lib/greeter.cc`
```c++
#include "greeter.h"

namespace simple_app {
    std::string GetGreet(const std::string& who) {
        return "Hello " + who;
    }
}
```
`src/lib/BUILD.bazel`

```
cc_library(
    name = "greeter_lib",
    srcs = ["greeter.cc"],
    hdrs = ["greeter.h"],
    # 'strip_include_prefix' allows consumers to include "greeter.h" 
    # directly instead of "src/lib/greeter.h"
    strip_include_prefix = ".", 
    visibility = ["//visibility:public"],
)
```
### 3. The Binary (`src/main`)
`src/main/main.cc`
```c++
#include <iostream>
#include "greeter.h" 

int main() {
    std::cout << simple_app::GetGreet("Bazel C++") << std::endl;
    return 0;
}
```
`src/main/BUILD.bazel`
```
cc_binary(
    name = "main",
    srcs = ["main.cc"],
    deps = [
        "//src/lib:greeter_lib",
    ],
)
```
### 4. Build & Run
```bash
bazel run //src/main:main
# Output: Hello Bazel C++
```

## 2.3 C++ with gRPC & Protobuf (The Hybrid Bridge)
Now we add the complex dependencies. We will define Protobuf and gRPC explicitly in the `WORKSPACE` to ensure they are perfectly synchronized.

### 1. Update `WORKSPACE` (Critical Step)
Replace or append the following to your `WORKSPACE` file. We explicitly load Protobuf v27.3 before gRPC to prevent version conflicts.
```
# WORKSPACE (Add this section)

# 1. Define Protobuf v27.3 (Explicitly)
http_archive(
    name = "com_google_protobuf",
    sha256 = "8bb0ae49d5a32b6504d559b5697733379d3211d9f4ba08f998f8a02e025d6b2d",
    strip_prefix = "protobuf-27.3",
    urls = ["https://github.com/protocolbuffers/protobuf/archive/v27.3.tar.gz"],
)

# 2. Load gRPC v1.66.0
http_archive(
    name = "com_github_grpc_grpc",
    urls = ["https://github.com/grpc/grpc/archive/refs/tags/v1.66.0.tar.gz"],
    sha256 = "eacf07e6354b6a30056b0338027b20c7f5a1da556a674d108cea1b8938d7abec",
    strip_prefix = "grpc-1.66.0",
)

# 3. Load gRPC Dependencies
load("@com_github_grpc_grpc//bazel:grpc_deps.bzl", "grpc_deps")
grpc_deps()

load("@com_github_grpc_grpc//bazel:grpc_extra_deps.bzl", "grpc_extra_deps")
grpc_extra_deps()
```
### 2. Define the Schema (src/proto)
`src/proto/greeter.proto`

```protobuf
syntax = "proto3";
package greeter;

service GreeterService {
  rpc SayHello (HelloRequest) returns (HelloReply) {}
}

message HelloRequest {
  string name = 1;
}

message HelloReply {
  string message = 1;
}
```
`src/proto/BUILD.bazel` We use the rules loaded from the `@com_github_grpc_grpc` repository.

```
load("@rules_proto//proto:defs.bzl", "proto_library")
load("@com_github_grpc_grpc//bazel:cc_grpc_library.bzl", "cc_grpc_library")

# 1. Abstract Schema
proto_library(
    name = "greeter_proto",
    srcs = ["greeter.proto"],
    visibility = ["//visibility:public"],
)

# 2. C++ Code Generation
cc_grpc_library(
    name = "greeter_cc_grpc",
    srcs = [":greeter_proto"],
    grpc_only = True,
    deps = ["@com_github_grpc_grpc//:grpc++"],
    visibility = ["//visibility:public"],
)
```
### 3. The C++ Server (src/server)
`src/server/server.cc`
```c++
#include <iostream>
#include <string>
#include <grpcpp/grpcpp.h>
#include "src/proto/greeter.grpc.pb.h"

using grpc::Server;
using grpc::ServerBuilder;
using grpc::ServerContext;
using grpc::Status;
using greeter::GreeterService;
using greeter::HelloRequest;
using greeter::HelloReply;

class GreeterServiceImpl final : public GreeterService::Service {
    Status SayHello(ServerContext* context, const HelloRequest* request,
                    HelloReply* reply) override {
        std::string prefix("Hello via gRPC, ");
        reply->set_message(prefix + request->name());
        return Status::OK;
    }
};

void RunServer() {
    std::string server_address("0.0.0.0:50051");
    GreeterServiceImpl service;

    ServerBuilder builder;
    builder.AddListeningPort(server_address, grpc::InsecureServerCredentials());
    builder.RegisterService(&service);
    std::unique_ptr<Server> server(builder.BuildAndStart());
    std::cout << "Server listening on " << server_address << std::endl;
    server->Wait();
}

int main() {
    RunServer();
    return 0;
}
```
`src/server/BUILD.bazel`

```
cc_binary(
    name = "server",
    srcs = ["server.cc"],
    deps = [
        "//src/proto:greeter_cc_grpc",
        "@com_github_grpc_grpc//:grpc++",
    ],
)
```
### 4. The C++ Client (src/client)
`src/client/client.cc`
```c++
#include <iostream>
#include <memory>
#include <string>
#include <grpcpp/grpcpp.h>
#include "src/proto/greeter.grpc.pb.h"

using grpc::Channel;
using grpc::ClientContext;
using grpc::Status;
using greeter::GreeterService;
using greeter::HelloRequest;
using greeter::HelloReply;

class GreeterClient {
 public:
  GreeterClient(std::shared_ptr<Channel> channel)
      : stub_(GreeterService::NewStub(channel)) {}

  std::string SayHello(const std::string& user) {
    HelloRequest request;
    request.set_name(user);
    HelloReply reply;
    ClientContext context;

    Status status = stub_->SayHello(&context, request, &reply);

    if (status.ok()) {
      return reply.message();
    } else {
      return "RPC failed";
    }
  }

 private:
  std::unique_ptr<GreeterService::Stub> stub_;
};

int main(int argc, char** argv) {
  std::string target_str = "localhost:50051";
  GreeterClient greeter(grpc::CreateChannel(
      target_str, grpc::InsecureChannelCredentials()));
  std::string user("Bazel User");
  std::string reply = greeter.SayHello(user);
  std::cout << "Greeter received: " << reply << std::endl;
  return 0;
}
```
`src/client/BUILD.bazel`
```
cc_binary(
    name = "client",
    srcs = ["client.cc"],
    deps = [
        "//src/proto:greeter_cc_grpc",
        "@com_github_grpc_grpc//:grpc++",
    ],
)
```
